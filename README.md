# Fake News Project

## Objectif
Récupérer des articles depuis Le Gorafi, les stocker dans un CSV et détecter s'ils sont fake ou real.

## Source utilisée
- Le Gorafi

## Données récupérées
- title
- summary
- source
- url
- label
- prediction
